# Earlier public PFN-DAG studies

`pfn-dag/` preserves the complete earlier public repository tree from commit `8ea24a5ce40955dcc797ab52dec90a53e0f5e602`. Every tracked file, including scientific outputs, registrations, source and the original README, retains its original bytes and Git file mode. The relocation is recorded in [the legacy snapshot manifest](../manifests/legacy-snapshot.json).

Start with [pfn-dag/README.md](pfn-dag/README.md) for its environment, commands, release assets and known test failures. Run those commands from `legacy/pfn-dag/` in a separate environment. Old absolute cluster paths and missing-artifact qualifications remain historical records; relocation does not make those workflows portable.

The existing [raw-mech_20260827 release](https://github.com/bowenzhaosh/pfn-supervision-public/releases/tag/raw-mech_20260827) and its assets remain attached to this repository. They belong to the earlier studies and are not the production inputs for the current supervision-randomness manuscript.
